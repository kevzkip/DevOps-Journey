# DevOps & SRE Engineering Journey

Welcome to my public DevOps and SRE learning repository. This repository documents my hands-on journey mastering Linux, Cloud engineering, and DevOps practices using a clean, isolated, and CLI-driven environment.

## Structure

* [`docs/`](docs/): Comprehensive documentation, logs, and tutorials (including environment setup).
* [`configs/`](configs/): Configuration templates and system setup files.
* [`scripts/`](scripts/): Automation and utility scripts.

## Environment

* **Host:** Windows 11 (Windows Terminal)
* **Environment:** WSL 2 (Ubuntu)
* **Version Control:** Git & GitHub (SSH)
